# Wave 4 existence scout (2026-10-30)

- **Master–detail:** No persistent source→target link routing found in Zen’s `src/zen/split-view/ZenViewSplitter.mjs` or Firefox’s `engine/browser/components/tabbrowser/content/tabsplitview.mjs`; ordinary splits exist. Whimsy already implements this in `src/zen/whimsy/WhimsyFollowerTabs.sys.mjs` (two-pane follower split). Reuse it. [Zen source](https://github.com/zen-browser/desktop/tree/dev/src/zen/split-view).
- **Page as Markdown:** Not found as a native page-content action. Zen’s `src/zen/common/modules/ZenCommonUtils.mjs:copyCurrentURLAsMarkdownToClipboard` copies only `[title](URL)`. Firefox’s `engine/browser/components/multilineeditor/multiline-editor.mjs` serializes editor content, not arbitrary pages. [Zen request #12557](https://github.com/zen-browser/desktop/discussions/12557) explicitly requests page conversion.
- **Current-page QR:** Already in Firefox: `engine/browser/components/sharing/SharePageAction.sys.mjs` → `SharingUtils.sys.mjs:showQRCodePanel`, backed by `engine/browser/components/qrcode/QRCodeGenerator.sys.mjs`. Sharing menus use `browser.shareqrcode.enabled`. Expose existing functionality; no generator needed.
- **Notes appearance:** Zen has no separate upstream Notes Library section (`src/zen/library/ZenLibrary.mjs`); [#9854](https://github.com/zen-browser/desktop/discussions/9854) proposes one. Inherited Firefox notes use a compact tab-attached text-editor panel (`engine/browser/components/tabbrowser/content/tabnote-menu.js`, plain textarea). Whimsy’s `src/zen/whimsy/content/whimsy-library-notes.mjs` instead provides a Library list with inline title/text editing and URL attachments. Historical Arc Notes were native, Markdown-capable documents opened from pinned tabs or Library/Peek ([official archive](https://start.arc.net/release-notes)); [retired April 2024](https://resources.arc.net/hc/en-us/articles/19233788518039-Phasing-Out-Arc-Notes). Live interactive web blocks belonged to **Easels’ Live Captures**, not documented Notes functionality (official archive, July 28, 2022). Do not conflate them.
