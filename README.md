### `Whimsy`

[![Releases](https://img.shields.io/github/v/release/ethankeshishian/whimsy?label=release)](https://github.com/ethankeshishian/whimsy/releases)
[![License: MPL 2.0](https://img.shields.io/badge/License-MPL_2.0-blue.svg)](http://mozilla.org/MPL/2.0/)

Whimsy is a delightful, Arc-inspired browser built as an overlay fork of Zen Browser and Mozilla Firefox. Spaces, container-backed profiles, split views, and Mini Whimsy quick windows keep browsing organized, with a command bar and assignable keyboard shortcuts close at hand.

- A Private Space, private tabs, and locked spaces keep sensitive browsing separate.
- AI chat with tabs, page and PDF summaries, agents, and scheduled routines, with provider and permission controls in Settings.
- A Library for notes, downloads, screenshots, and archived tabs, plus Easel canvases for live page captures.
- Link hints, instant results, cookie banner blocking, and per-site controls for everyday browsing.

### Download & Updates

Download the Apple silicon Mac `.dmg` from [Releases](https://github.com/ethankeshishian/whimsy/releases/latest), drag Whimsy to Applications, and open it. If macOS cannot verify the developer, use **System Settings → Privacy & Security → Open Anyway** for the first launch.

Whimsy downloads updates in the background and installs them on restart. Choose **Release** (the default) or **Dev** in **Settings → About Whimsy → Channel**. Dev builds appear as [pre-releases](https://github.com/ethankeshishian/whimsy/releases) and include changes before Release.

### Versions & Foundations

- Built on **Zen Browser** `1.24b`
- Powered by **Mozilla Firefox** (Gecko) `159.0`
